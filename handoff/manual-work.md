기능: 설정
변경: 신규 개발 (CS-001)

## 수동 작업

- [ ] 1. 앱을 기기나 에뮬레이터에 설치한다
  Android Studio에서 이 저장소를 열고, 위쪽 기기 목록에서 Android 8.0(API 26) 이상인 기기나 에뮬레이터를 고른 뒤 Run(▶)을 누른다. 디버그 빌드로 설치된다(수동 확인 R-21의 Device Explorer는 디버그 빌드여야 열린다).
- [ ] 2. 두 출처의 API 키를 발급받아 둔다
  Twelve Data: 브라우저에서 `https://twelvedata.com/register`로 가입한 뒤 대시보드의 API Keys에서 키를 복사한다. FRED: `https://fredaccount.stlouisfed.org/apikeys`에서 계정을 만들고 Request API Key로 키를 받아 복사한다. 두 키를 기기에 붙여 넣을 수 있게 메모 앱 등에 둔다(키는 저장소나 채팅에 올리지 않는다).
- [ ] 3. 확인 중 상태를 볼 때 쓸 느린 네트워크를 준비한다
  수동 확인 R-32·R-37·R-38은 응답이 오기 전에 손을 써야 한다. 에뮬레이터라면 오른쪽 도구 막대의 ⋯(Extended controls) > Cellular에서 Network type을 GSM, Signal strength를 Poor로 바꾼다(Wi‑Fi는 끈다). 실제 기기라면 개발자 옵션의 네트워크 속도 제한이나 약한 신호의 장소를 쓴다. 확인이 끝나면 원래대로 되돌린다.

## 수동 확인

- [ ] R-01: Given 앱이 설치됨 / When 앱을 연다 / Then 설정 화면이 바로 보인다
  확인 방법: 앱을 설치한 뒤 앱 서랍에서 "학반꿀" 아이콘을 눌러 연다. 첫 화면이 설정 화면인지 본다.
- [ ] R-02: Given 설정 화면 / When 화면을 본다 / Then 위에서 아래로 위쪽 줄("설정", 뒤로 가기 없음), 안내 "데이터를 받으려면 출처마다 키가 필요합니다. 키는 이 기기에만 저장됩니다.", 출처 카드들이 놓인다
  확인 방법: 설정 화면을 열고 맨 위에서부터 차례로 본다. 위쪽 줄에 "설정"이 있고 왼쪽에 뒤로 가기 화살표가 없는지, 그 아래 안내 문구, 그 아래 카드들이 오는지 본다.
- [ ] R-03 (카드 표시): Given 설정 화면 / When 화면을 본다 / Then Twelve Data 카드, 그 아래 FRED 카드가 보인다
  확인 방법: 설정 화면을 열고 카드 순서를 본다. 첫 카드가 Twelve Data, 그 아래가 FRED인지 본다.
- [ ] R-04: Given 키 없음인 카드와 저장됨인 카드 / When 화면을 본다 / Then 두 카드 모두 출처 이름, 그 아래 무엇에 쓰는 키인지 한 줄(Twelve Data: 주식과 ETF 가격 / FRED: 금리와 채권 지표), 출처 이름 오른쪽에 상태 딱지가 있다
  확인 방법: 한 출처는 키를 저장하고(수동 작업 2의 키) 다른 출처는 비워 둔 채 설정 화면을 본다. 두 카드 모두 이름, 그 아래 설명 한 줄, 이름 오른쪽 딱지가 있는지 본다.
- [ ] R-05 (딱지의 글과 색): Given 키 없음, 저장됨, 틀림인 카드 / When 화면을 본다 / Then 딱지가 "키 없음" 회색, "저장됨" 파랑, "틀림" 빨강으로 보이고 글이 늘 함께 있다
  확인 방법: 키 없음 카드, 저장된 카드를 화면에서 본다. 틀림 카드는 Twelve Data에 `wrongkey123`을 넣고 저장해 만든다(입력 모드 틀림). 저장 모드의 틀림은 R-28처럼 미리보기 "틀림 (저장 모드)"에서 본다. 각 딱지의 글과 색을 본다.
- [ ] R-06 (요소 표시): Given 키 없음인 카드 / When 화면을 본다 / Then 이름표 "API 키" 입력 칸(빈 칸에 "키를 붙여 넣으세요"), "키 발급받기"와 그 아래 "무료, 카드 등록 없음", "저장" 버튼이 보인다
  확인 방법: 키가 저장되지 않은 카드를 본다. "API 키" 이름표가 붙은 입력 칸(비어 있을 때 "키를 붙여 넣으세요"), 왼쪽 "키 발급받기"와 그 아래 "무료, 카드 등록 없음", 오른쪽 "저장" 버튼이 있는지 본다.
- [ ] R-07 (요소 표시): Given 키 `…5678`이 저장된 카드 / When 화면을 본다 / Then 입력 칸·발급 안내·저장 버튼은 없고, 끝 네 글자 `5678`만 보이게 가려진 키, 그 오른쪽 키 보기 버튼, "키 지우기" 버튼이 보인다
  확인 방법: 수동 작업 2의 맞는 키를 저장한 카드를 본다(`5678`은 예시이므로 저장한 키의 끝 네 글자로 확인한다). 입력 칸·발급 안내·저장 버튼이 없고, 끝 네 글자만 보이는 가린 키, 그 오른쪽 눈 모양 버튼, "키 지우기" 버튼이 있는지 본다.
- [ ] R-08 (표시): Given 키 없음인 Twelve Data 카드 / When 틀린 키 `wrongkey123`을 넣고 저장 / Then 입력 칸에 `wrongkey123`이 남고 테두리가 빨갛고, 딱지는 "틀림", 발급 안내와 저장 버튼은 그대로 있다
  확인 방법: Twelve Data 카드가 키 없음일 때 입력 칸에 `wrongkey123`을 치고 "저장"을 누른다. 확인이 끝난 뒤 입력 칸 글자, 테두리 색, 딱지, 발급 안내와 저장 버튼이 남아 있는지 본다.
- [ ] R-10: Given 키 없음인 카드 / When 입력 칸에 키를 치고, 지운 뒤 복사한 키를 붙여 넣는다 / Then 두 방법 모두 입력 칸에 들어간다
  확인 방법: 키 없음 카드의 입력 칸을 눌러 자판으로 아무 글자나 친다. 글자를 모두 지운 뒤, 메모 앱 등에서 키를 복사해 와 입력 칸을 길게 눌러 "붙여넣기"한다. 두 번 모두 입력 칸에 글자가 들어가는지 본다.
- [ ] R-11 (출처별 요청 모양): Given 두 출처에서 받은 맞는 키 / When 각 카드에 넣고 저장 / Then 두 카드 모두 "저장됨"이 된다
  확인 방법: 수동 작업 2에서 받은 Twelve Data 키를 Twelve Data 카드에, FRED 키를 FRED 카드에 붙여 넣고 각각 "저장"을 누른다. 확인이 끝난 뒤 두 카드 딱지가 모두 "저장됨"인지 본다.
- [ ] R-14: Given 저장됨인 카드 / When "키 지우기"를 누른다 / Then "이 키를 지울까요?" 창이 뜬다
  확인 방법: 키가 저장된 카드에서 "키 지우기"를 누르고 "이 키를 지울까요?" 창이 뜨는지 본다. 창은 "취소"로 닫는다(지우지 않으려면).
- [ ] R-15 (브라우저 열기): Given 키 없음인 두 카드 / When 각각 "키 발급받기"를 누른다 / Then 브라우저에서 Twelve Data는 `https://twelvedata.com/register`, FRED는 `https://fredaccount.stlouisfed.org/apikeys`가 열린다
  확인 방법: 두 카드가 키 없음일 때 각 카드의 "키 발급받기"를 누른다. 열린 브라우저의 주소창 주소를 보고, 뒤로 가기로 앱에 돌아와 다른 카드도 같은 방법으로 본다.
- [ ] R-18 (실제 틀린 키): Given 두 출처 카드가 키 없음 / When 각 카드에 틀린 키 `wrongkey123`을 넣고 저장 / Then 두 카드 모두 "키가 맞지 않습니다. 다시 확인해 주세요."가 보이고 저장되지 않는다(앱을 껐다 켜면 키 없음)
  확인 방법: 두 카드가 키 없음일 때 각 카드에 `wrongkey123`을 넣고 "저장"을 누른다. 두 카드의 안내 문구를 본다. 그다음 최근 앱 화면에서 학반꿀을 위로 밀어 닫고 다시 열어, 두 카드가 키 없음인지 본다.
- [ ] R-19 (실제 연결 끊김): Given 비행기 모드 / When 맞는 키를 넣고 저장 / Then "연결이 안 되어 키를 확인하지 못했습니다. 연결을 확인하고 다시 눌러 주세요."가 보이고, 넣은 키가 남고, 딱지는 "키 없음" 그대로다
  확인 방법: 키 없음 카드가 있는 상태에서 기기의 빠른 설정에서 비행기 모드를 켠다. 그 카드에 맞는 키를 넣고 "저장"을 누른다. 안내 문구, 입력 칸 글자, 딱지를 본다. 끝나면 비행기 모드를 끈다.
- [ ] R-20 (저장된 키와 상태가 남음): Given Twelve Data 저장됨 / When 앱을 완전히 껐다 켠다 / Then Twelve Data는 저장됨, 가려진 키가 그대로 보인다
  확인 방법: Twelve Data 키를 저장해 "저장됨"으로 만든다. 최근 앱 화면에서 학반꿀을 위로 밀어 닫는다(또는 기기 설정 > 앱 > 학반꿀 > 강제 종료). 다시 열어 Twelve Data 딱지와 가린 키를 본다.
- [ ] R-21: Given 키를 저장함 / When Android Studio의 Device Explorer로 `datastore/api_keys.preferences_pb`를 연다 / Then 저장한 키 글자가 그대로 보이지 않는다
  확인 방법: 키를 하나 저장한다. Android Studio에서 View > Tool Windows > Device Explorer를 열고 `/data/data/com.hak.hakbanggul/files/datastore/api_keys.preferences_pb`를 두 번 눌러 연다. 저장한 키 글자가 그대로 보이지 않는지 본다(디버그 빌드여야 열린다).
- [ ] R-22: Given 키를 저장함 / When 앱을 지우고 다시 설치해 연다 / Then 두 출처 모두 키 없음이다
  확인 방법: 키를 저장한다. 기기에서 학반꿀을 삭제하고 Android Studio의 Run으로 다시 설치해 연다. 두 카드 모두 키 없음인지 본다.
- [ ] R-28 (표시): Given 저장되어 있던 키가 나중에 거절된 상태의 카드(이 변경에는 데이터를 받는 기능이 없어 실제로 만들 수 없으므로 Android Studio의 미리보기로 본다) / When 미리보기를 연다 / Then 딱지 "틀림", 키는 가려진 채, 그 아래 "키가 거절됐습니다. 지우고 다시 넣어 주세요."와 키 보기·"키 지우기" 버튼이 보인다
  확인 방법: Android Studio에서 `app/src/main/java/com/hak/hakbanggul/feature/settings/presentation/SettingsScreen.kt`를 열고 오른쪽 위의 Split 또는 Design 보기를 누른다. 미리보기 목록에서 "틀림 (저장 모드)"를 찾아 딱지, 가린 키, 거절 안내, 눈 모양 버튼과 "키 지우기" 버튼을 본다.
- [ ] R-32 (진행 표시와 "확인 중"): Given 키 없음인 Twelve Data 카드 / When 키를 넣고 저장 / Then 응답이 올 때까지 저장 버튼 자리에 돌아가는 진행 표시와 "확인 중"이 보이고, 그 카드의 입력 칸은 비활성이며, FRED 카드는 그대로 쓸 수 있다
  확인 방법: Twelve Data 카드가 키 없음일 때 키를 넣고 "저장"을 누르고, 응답이 오기 전에 화면을 본다. 저장 버튼 자리의 돌아가는 표시와 "확인 중", 입력 칸 비활성, FRED 카드 입력 칸에 글자를 칠 수 있는지 본다. 응답이 너무 빨라 보기 어려우면 수동 작업 3대로 네트워크를 느리게 한다.
- [ ] R-33 (앱을 다시 켜면 가림): Given 키 보기로 키 전체를 보는 중 / When 앱을 완전히 껐다 켠다 / Then 키가 가려져 있다
  확인 방법: 키가 저장된 카드에서 눈 모양 버튼을 눌러 키 전체를 보이게 한다. 최근 앱 화면에서 학반꿀을 위로 밀어 닫고 다시 열어, 키가 가려져 있는지 본다.
- [ ] R-35: Given "이 키를 지울까요?" 창 / When "취소" / Then 창이 닫히고 키와 딱지가 그대로다
  확인 방법: 키가 저장된 카드에서 "키 지우기"를 누르고 창에서 "취소"를 누른다. 창이 닫히고 키와 딱지가 그대로인지 본다.
- [ ] R-37 (화면을 벗어났다 돌아오기): Given 맞는 키를 넣고 저장해 확인 중 / When 바로 홈으로 나갔다가 몇 초 뒤 돌아온다 / Then 아직 확인 중이면 확인 중 표시가, 끝났으면 저장됨 모양이 보인다. 틀린 키로 같은 일을 하면 넣은 키와 "키가 맞지 않습니다…"가 보인다
  확인 방법: 수동 작업 3대로 네트워크를 느리게 한다. 맞는 키를 넣고 "저장"을 누르자마자 홈 버튼으로 나간다. 몇 초 뒤 최근 앱 화면에서 학반꿀로 돌아와 카드 모양을 본다. 같은 일을 `wrongkey123`으로 한 번 더 해 넣은 키와 "키가 맞지 않습니다…"가 보이는지 본다. 끝나면 네트워크 속도를 되돌린다.
- [ ] R-38: Given 맞는 키를 넣고 저장해 확인 중 / When 응답 전에 앱을 강제 종료하고 다시 켠다 / Then 그 출처는 키 없음이다(받아들여지기 전에 종료한 경우)
  확인 방법: 수동 작업 3대로 네트워크를 느리게 한다. 맞는 키를 넣고 "저장"을 누르자마자 PC의 터미널에서 `adb shell am force-stop com.hak.hakbanggul`을 실행한다(또는 기기 설정 > 앱 > 학반꿀 > 강제 종료). 앱을 다시 열어 그 출처가 키 없음인지 본다. 끝나면 네트워크 속도를 되돌린다.
