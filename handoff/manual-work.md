## 수동 작업

- [ ] 1. 앱을 기기나 에뮬레이터에 설치한다
  Android Studio에서 이 저장소를 열고, 위쪽 기기 목록에서 Android 8.0(API 26) 이상인 기기나 에뮬레이터를 고른 뒤 Run(▶)을 누른다. 디버그 빌드로 설치된다(수동 작업 3의 Device Explorer는 디버그 빌드여야 열린다). 설정 기능 확인 때 설치한 앱이 있으면 그 위에 설치되어 저장한 키가 남는다.
- [ ] 2. 두 출처의 맞는 키를 저장해 둔다
  앱의 메뉴(점 세 개) > "설정"에서 Twelve Data 카드와 FRED 카드에 각 출처의 키를 붙여 넣고 "저장"해 두 카드 모두 "저장됨"이 되게 한다. 키가 없으면 Twelve Data는 `https://twelvedata.com/register`, FRED는 `https://fredaccount.stlouisfed.org/apikeys`에서 받는다. 키 하나를 지우는 확인(R-04, R-15, R-49 등)을 한 뒤에는 다시 저장해 둔다.
- [ ] 3. "받아 둔 값이 없음"을 만드는 법을 익혀 둔다
  키는 남기고 받아 둔 값만 지우는 방법이다. Android Studio 위쪽 도구 막대의 Stop(■)으로 앱을 끈 뒤, View > Tool Windows > Device Explorer를 열고 `/data/data/com.hak.hakbanggul/databases/`에서 `hakbanggul.db`, `hakbanggul.db-shm`, `hakbanggul.db-wal`을 골라 오른쪽 버튼 > Delete로 지운다. 그다음 앱을 연다. Device Explorer를 쓸 수 없으면 기기의 설정 > 애플리케이션 > 학반꿀 > 저장공간 > 데이터 삭제를 쓰되, 이때는 키도 지워지므로 앱을 연 뒤 설정에서 두 키를 다시 저장하고 뒤로 가기로 돌아온다.
- [ ] 4. 받는 중 상태를 볼 때 쓸 느린 네트워크를 준비한다
  수동 확인 R-16, R-19 (받는 중), R-22, R-55는 받는 동안에 보거나 손을 써야 한다. 에뮬레이터라면 오른쪽 도구 막대의 ⋯(Extended controls) > Cellular에서 Network type을 GSM, Signal strength를 Poor로 바꾼다(Wi‑Fi는 끈다). 실제 기기라면 개발자 옵션의 네트워크 속도 제한이나 약한 신호의 장소를 쓴다. 그래도 너무 빨리 끝나면 R-16·R-19 (받는 중)은 미리보기로 본다. 확인이 끝나면 원래대로 되돌린다.

  확인 방법: 앱을 설치한 뒤(수동 작업 1) 최근 앱 화면에서 학반꿀을 위로 밀어 닫고, 앱 서랍에서 "학반꿀" 아이콘을 눌러 연다. 첫 화면이 시장 분위기 화면(위쪽 줄 왼쪽에 "학반꿀")인지 본다.
