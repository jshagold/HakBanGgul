## 수동 작업

- [ ] 1. 이 변경을 기기에 설치한다
  Android Studio에서 Run으로 기기에 덮어 설치한다. 앱을 지우지 않아야 저장된 두 키(Twelve Data, FRED)와 받아 둔 값이 남는다. R-02는 Android 12 이상 기기에서만 볼 수 있다. 설치한 뒤 앱을 한 번 열어 시장 분위기 화면에 판정이 보이는지 확인한다.
- [ ] 2. "받아 둔 값이 없음"을 만드는 법을 익혀 둔다
  키는 남기고 받아 둔 값만 지우는 방법이다(R-05에서 쓴다). Android Studio 위쪽 도구 막대의 Stop(■)으로 앱을 끈 뒤, View > Tool Windows > Device Explorer를 열고 `/data/data/com.hak.hakbanggul/databases/`에서 `hakbanggul.db`, `hakbanggul.db-shm`, `hakbanggul.db-wal`을 골라 오른쪽 버튼 > Delete로 지운다. Device Explorer를 쓸 수 없으면 기기의 설정 > 애플리케이션 > 학반꿀 > 저장공간 > 데이터 삭제를 쓰되, 이때는 키도 지워지므로 앱을 연 뒤 설정에서 두 키를 다시 저장한다.
- [ ] 3. 날짜가 바뀌어야 보는 항목을 날을 나눠 본다
  새 종가는 한국 시각으로 화~토요일 아침에 나온다(미국 휴장일 다음 날은 안 나온다). 한 번 받으면 다음 새 종가까지 "새 종가가 나옴"을 다시 만들 수 없어, 아래 항목은 새 종가가 나오는 아침마다 하나씩 본다. 아래 순서를 권한다.
  - 설치한 날: 날짜와 상관없는 항목(R-01~R-16, R-18, R-19, R-25, R-27, R-32, R-37, R-39, R-41~R-43)을 모두 본다. 끝나면 R-21·R-23·R-24의 준비(위젯 놓기, 모두 치웠다가 다시 놓기, 기기 껐다 켜기)를 하고 앱을 열지 않는다.
  - 다음 날 아침: R-21, R-23, R-24를 본다. 저녁에 R-20을 준비한다(놓인 위젯을 모두 치우고, 최근 앱 목록에서 앱을 지운다).
  - 그다음 날 아침: R-20. 저녁에 R-22를 같게 준비한다.
  - 그다음 날 아침: R-22. 저녁에 위젯을 하나 놓고 앱을 강제 종료한다(R-38 준비).
  - 그다음 날 아침: R-38. 저녁에 앱을 강제 종료한다(R-17 준비).
  - 그다음 날 아침: R-17.
  - 강제 종료(설정 > 애플리케이션 > 학반꿀 > 강제 종료)를 하는 까닭: 위젯이 놓여 있으면 약 6시간마다 뒤에서 받아, 아침에 보기 전에 새 종가를 이미 받아 버린다. 강제 종료하면 앱이 다시 깨어날 때까지(위젯을 누르거나 앱을 열 때까지) 뒤에서 받지 않는다.

## 수동 확인

- 날짜가 바뀌는 것으로 보는 항목은 새 종가가 나온 뒤에 본다. 미국 장이 하루 열리고 닫힌 뒤(한국 시각으로 다음 날 아침 이후)다. 주말과 미국 휴장일에는 날짜가 바뀌지 않는다.
- R-21, R-23, R-24는 하루를 넘겨야 보인다. 한 번에 볼 수 있게 이어서 한다: 위젯을 놓은 날 R-23의 치우고 다시 놓기와 R-24의 기기 껐다 켜기를 하고, 앱을 열지 않은 채 다음 날 위젯의 날짜를 본다.

- [ ] R-01: Given 앱을 설치함 / When 홈 화면에서 위젯을 고르는 목록을 연다 / Then 학반꿀 아래에 "장세 (작게)"와 "장세 (크게)" 둘이 따로 보인다
  - 확인 방법: 홈 화면의 빈 곳을 길게 눌러 "위젯"을 연다. 목록에서 학반꿀을 찾아 누르고, 그 아래에 "장세 (작게)"와 "장세 (크게)"가 따로 있는지 본다.
- [ ] R-02: Given Android 12 이상 기기 / When 위젯을 고르는 목록에서 두 위젯을 본다 / Then 각 미리 보기가 그 위젯의 불장인 날 모습("지금 장은", 빨간 "불장", "11월 23일 종가", 오른쪽 위 새로 고침 아이콘)이다
  - 확인 방법: Android 12 이상 기기에서 R-01과 같게 학반꿀의 위젯 목록을 연다. 두 위젯의 미리 보기 그림에 "지금 장은", 빨간 "불장", "11월 23일 종가", 오른쪽 위 새로 고침 아이콘이 있는지 본다. 지금 앱의 판정과 상관없이 늘 이 모습이어야 한다.
- [ ] R-03 (여러 개 놓기): Given 키가 저장되어 있고 받아 둔 값이 있음 / When 작은 위젯 둘과 큰 위젯 하나를 함께 놓는다 / Then 셋 모두 놓이고 같은 단계와 날짜를 보여 준다
  - 확인 방법: 앱에서 판정이 보이는 상태에서, 위젯 목록에서 "장세 (작게)"를 두 번, "장세 (크게)"를 한 번 끌어다 홈 화면에 놓는다. 셋 모두 놓이고, 단계 이름과 "M월 D일 종가"가 셋 다 같은지 본다.
- [ ] R-04: Given 위젯을 놓음 / When 위젯을 길게 누른다 / Then 크기를 바꾸는 손잡이가 없다
  - 확인 방법: 작은 위젯과 큰 위젯을 각각 길게 누른다. 위젯 둘레에 크기를 바꾸는 테두리나 손잡이가 나타나지 않는지 본다(홈 화면 앱이 띄우는 메뉴는 있어도 된다).
- [ ] R-05 (표시): Given 위젯을 놓음 / When 키가 모두 저장되고 받아 둔 값이 있을 때, 설정에서 키 하나를 지웠을 때, 키는 저장되어 있는데 받아 둔 값이 없고 받기에 실패했을 때를 차례로 본다 / Then 차례로 판정, 키 안내, 받지 못함이 보인다
  - 확인 방법:
    1. 두 키가 저장되고 앱에 판정이 보이는 상태에서 홈으로 나가 위젯에 판정("지금 장은", 단계 이름, 날짜)이 보이는지 본다.
    2. 앱의 설정 화면에서 Twelve Data 키의 "키 지우기"를 눌러 지우고 홈으로 나간다. 위젯에 "학반꿀", "키를 넣어 주세요"가 보이는지 본다. 설정에서 키를 다시 저장한다.
    3. 수동 작업 2의 방법으로 받아 둔 값을 지운다. 비행기 모드를 켜고 앱을 연다(받기에 실패한다). 홈으로 나가 위젯에 "학반꿀", "데이터를 받지 못했습니다"가 보이는지 본다.
    4. 비행기 모드를 그대로 두고 R-08~R-11, R-13(받지 못함), R-14(받지 못함)를 이어서 본 뒤, 비행기 모드를 끄고 앱을 열어 판정을 다시 받는다.
- [ ] R-06 (화면 배치): Given 키가 모두 저장되고 받아 둔 값이 있음 / When 두 위젯을 본다 / Then 위에서 아래로 "지금 장은", 단계 이름(크게, 단계의 색), "M월 D일 종가"다
  - 확인 방법: 판정이 보이는 작은 위젯과 큰 위젯에서, 위에서 아래로 "지금 장은", 큰 글자로 단계의 색을 입힌 단계 이름, "M월 D일 종가"(예: "11월 24일 종가") 순서인지 본다.
- [ ] R-08 (화면 표시): Given 받지 못함 상태 / When 두 위젯을 본다 / Then 위에서 아래로 "학반꿀", "데이터를 받지 못했습니다"다
  - 확인 방법: R-05의 3처럼 받지 못함을 만든 뒤, 두 위젯에서 위에서 아래로 "학반꿀", "데이터를 받지 못했습니다" 순서인지 본다.
- [ ] R-09: Given 받지 못함 상태 / When 작은 위젯을 본다 / Then "데이터를 받지 못했습니다"가 한 줄에 들어가지 않으면 "데이터를" 다음이나 "받지" 다음처럼 띄어쓰기에서 넘어가고, 낱말 가운데("못했습" / "니다" 등)에서 넘어가지 않는다
  - 확인 방법: 받지 못함 상태의 작은 위젯에서 "데이터를 받지 못했습니다"가 넘어가는 자리를 본다. 한 줄에 다 들어가 넘어가지 않으면 기기의 설정 > 디스플레이 > 글자 크기와 스타일에서 글자 크기를 가장 크게 올려 다시 본다. 줄이 띄어쓰기에서만 넘어가는지 보고, 끝나면 글자 크기를 되돌린다.
- [ ] R-10: Given 판정, 키 안내, 받지 못함 / When 작은 위젯을 본다 / Then 판정은 세 줄, 키 안내와 받지 못함은 두 줄(문구가 넘어가면 그만큼 더)이 위아래로 붙어 카드 세로 가운데에 놓인다
  - 확인 방법: R-05의 세 상태마다 작은 위젯을 본다. 글 줄들이 서로 붙어 한 덩어리로 카드의 위아래 가운데에 놓이는지(위나 아래로 쏠리지 않는지) 본다.
- [ ] R-11 (화면 배치): Given 판정, 키 안내, 받지 못함 / When 두 위젯을 본다 / Then 큰 위젯은 첫 줄이 위쪽, 단계 이름이나 안내 문구가 가운데, 마지막 줄(판정은 날짜, 키 안내와 받지 못함은 "눌러서 앱 열기")이 아래쪽이다. 작은 위젯에는 "눌러서 앱 열기"가 없다
  - 확인 방법: R-05의 세 상태마다 두 위젯을 본다. 큰 위젯에서 첫 줄("지금 장은" 또는 "학반꿀")이 위쪽, 단계 이름이나 안내 문구가 가운데, 마지막 줄(판정은 날짜, 키 안내와 받지 못함은 "눌러서 앱 열기")이 아래쪽에 있는지 본다. 작은 위젯에는 어느 상태에서도 "눌러서 앱 열기"가 없는지 본다.
- [ ] R-12: Given 위젯을 놓음 / When 기기를 어두운 화면으로 바꾼다 / Then 위젯은 흰 카드와 같은 글 색 그대로다
  - 확인 방법: 빠른 설정이나 설정 > 디스플레이에서 다크 모드를 켜고 홈 화면으로 돌아온다. 두 위젯이 흰 카드에 같은 글 색 그대로인지 본다. 끝나면 다크 모드를 끈다.
- [ ] R-13: Given 그날의 단계(하나), 키 안내, 받지 못함, 새로 고침을 눌러 받는 중의 모습 / When 각 모습에서 두 위젯을 시안 `https://claude.ai/artifact/LuRSF8bSPDqruAbnUSfye9`의 "위젯 · 작은 위젯 (2×1)", "위젯 · 큰 위젯 (2×2)"의 같은 모습과 나란히 놓고 본다 / Then 배치, 간격, 크기, 색이 같다. 위젯 크기는 홈 화면 앱에 따라 시안과 다를 수 있고, 여백·글자 크기·버튼 자리가 같으면 된다. 그날이 아닌 세 단계는 만들어 볼 수 없어 R-32로 색만 본다
  - 확인 방법: PC 브라우저에서 시안을 열고 "위젯 · 작은 위젯 (2×1)"과 "위젯 · 큰 위젯 (2×2)" 화면을 띄운다. 기기의 홈 화면에서 두 위젯을 네 모습으로 만들며 시안의 같은 모습과 나란히 본다.
    - 그날의 단계: 판정이 보이는 위젯과 시안의 같은 단계 모습.
    - 키 안내: R-05의 2처럼 키 하나를 지운 위젯과 시안의 키 안내 모습(버튼이 흐림).
    - 받지 못함: R-05의 3처럼 만든 위젯과 시안의 받지 못함 모습.
    - 받는 중: 새로 고침 버튼을 누른 위젯과 시안의 받는 중 모습(버튼 자리에 진행 표시). 진행 표시가 짧게 지나가면 빠른 설정의 화면 녹화로 찍어 멈춰 본다.
    카드의 테두리와 모서리, 안쪽 여백, 줄 사이, 글자 크기와 굵기, 글 색, 오른쪽 위 버튼(또는 진행 표시)의 자리와 크기가 같은지 본다.

- [ ] R-15: Given 앱에서 설정 화면을 연 채 홈으로 나감 / When 위젯의 버튼 밖을 누른다 / Then 설정 화면이 아니라 시장 분위기 화면이 보인다. 뒤로 가기를 누르면 앱을 나간다(설정 화면으로 돌아가지 않는다)
  - 확인 방법: 앱을 열고 오른쪽 위 메뉴의 "설정"으로 설정 화면을 연 채 홈 버튼으로 나간다. 위젯의 버튼 밖을 누른다. 시장 분위기 화면이 보이는지 보고, 기기의 뒤로 가기를 눌러 설정 화면이 아니라 홈 화면으로 나가는지 본다.

- [ ] R-18: Given 위젯이 판정을 보여 줌 / When 설정에서 키 하나를 지우고 홈으로 나갔다가, 다시 키를 저장하고 홈으로 나간다 / Then 지운 뒤에는 키 안내(버튼 흐림), 다시 저장한 뒤에는 판정이 보인다
  - 확인 방법: 앱의 설정 화면에서 FRED 키의 "키 지우기"로 키를 지우고 홈으로 나간다. 위젯이 "키를 넣어 주세요"이고 오른쪽 위 버튼이 흐린지 본다. 앱으로 돌아가 FRED 키를 다시 넣어 "저장"하고, "저장됨"이 보이면 홈으로 나가 위젯에 판정이 보이는지 본다.
- [ ] R-19 (표시): Given 위젯이 키 안내를 보여 줌(키 하나를 지움) / When 키를 다시 저장하고 곧바로 홈으로 나가 위젯을 지켜본다 / Then 키 안내에서 판정으로 바뀌고, 그 사이 "데이터를 받지 못했습니다"가 스치지 않는다
  - 확인 방법: R-18처럼 키 하나를 지워 위젯이 키 안내인 상태를 만든다. 빠른 설정의 화면 녹화를 켜고, 설정에서 키를 다시 저장해 "저장됨"이 보이자마자 홈으로 나가 위젯을 몇 초 지켜본다. 녹화를 멈추고 돌려 보며, 키 안내에서 판정으로 바뀌는 사이에 "데이터를 받지 못했습니다"가 한 번도 보이지 않는지 본다.
- [ ] R-20 (놓을 때 받음): Given 마지막으로 받은 뒤 6시간이 넘고 새 종가가 나옴, 앱이 꺼져 있음(최근 앱 목록에서 지움), 위젯이 없음 / When 위젯을 놓고 앱을 열지 않고 기다린다 / Then 잠시 뒤 위젯의 날짜가 새 종가 날짜로 바뀐다
  - 확인 방법: 수동 작업 3대로 전날 저녁에 놓인 위젯을 모두 치우고 최근 앱 목록에서 앱을 지워 둔다. 새 종가가 나온 아침에 앱을 열지 않고 위젯을 하나 놓는다. 처음에는 전날 날짜가 보이고, 1~2분 안에 새 종가 날짜로 바뀌는지 본다.
- [ ] R-21 (앱을 열지 않아도 받아짐): Given 위젯을 놓고 앱을 끔 / When 앱을 열지 않고 다음 날까지 둔다 / Then 다음 날 위젯의 날짜가 놓은 날보다 뒤의 새 종가 날짜로 바뀌어 있다
  - 확인 방법: 수동 작업 3대로 설치한 날 위젯을 놓고 최근 앱 목록에서 앱을 지운 뒤 위젯의 날짜를 적어 둔다(R-23, R-24 준비도 이어서 한다). 앱을 열지 않고 다음 날 아침에 위젯의 날짜가 적어 둔 날보다 뒤의 날짜인지 본다.
- [ ] R-22: Given 마지막으로 받은 뒤 6시간이 넘고 새 종가가 나옴, 앱이 꺼져 있음, 위젯이 없음, 비행기 모드 / When 위젯을 놓고 기다린 뒤 비행기 모드를 끈다 / Then 비행기 모드 동안에는 날짜가 그대로이고, 끈 뒤 잠시 뒤 새 종가 날짜로 바뀐다
  - 확인 방법: 수동 작업 3대로 전날 저녁에 놓인 위젯을 모두 치우고 최근 앱 목록에서 앱을 지워 둔다. 새 종가가 나온 아침에 비행기 모드를 켜고, 앱을 열지 않고 위젯을 하나 놓는다. 3분쯤 기다리며 날짜가 전날 그대로인지 본다. 비행기 모드를 끄고 연결이 잡힌 뒤 1~2분 안에 새 종가 날짜로 바뀌는지 본다.
- [ ] R-23: Given 위젯이 놓여 있음 / When 놓인 위젯을 모두 치웠다가 다시 놓고, 앱을 열지 않고 다음 날까지 둔다 / Then 다음 날 위젯의 날짜가 새 종가 날짜로 바뀌어 있다
  - 확인 방법: 설치한 날(R-21과 같은 날) 놓인 위젯을 모두 치웠다가 다시 하나 놓고, 최근 앱 목록에서 앱을 지운다. 앱을 열지 않고 다음 날 아침에 위젯의 날짜가 새 종가 날짜인지 본다.
- [ ] R-24: Given 위젯이 놓여 있음 / When 기기를 껐다 켜고, 앱을 열지 않고 다음 날까지 둔다 / Then 켠 뒤 위젯이 판정을 보여 주고(빈 카드나 오류가 아님), 다음 날 날짜가 새 종가 날짜로 바뀌어 있다
  - 확인 방법: R-23을 한 뒤 같은 날 기기를 껐다 켠다. 켠 뒤 잠금을 풀고 홈 화면의 위젯이 판정을 보여 주는지(빈 카드, "데이터를 받지 못했습니다", 위젯을 불러오지 못했다는 안내가 아닌지) 본다. 앱을 열지 않고 다음 날 아침에 위젯의 날짜가 새 종가 날짜인지 본다.
- [ ] R-25 (앱과 같음): Given 위젯이 판정을 보여 줌 / When 앱을 열어 종합 판정 카드를 본다 / Then 위젯의 단계 이름과 날짜가 카드의 "지금 장은" 아래 단계 이름, 기준 날짜와 같다
  - 확인 방법: 위젯의 단계 이름과 날짜를 본 뒤, 위젯을 눌러 앱을 연다. 시장 분위기 화면의 종합 판정 카드에서 "지금 장은" 아래 단계 이름과 "M월 D일 종가 기준 (미국)"의 날짜가 위젯과 같은지 본다.
- [ ] R-27 (실패해도 다시 돌리지 않음): R-42와 함께 본다
  - 확인 방법: R-42의 확인 방법을 따른다.
- [ ] R-32: Given 위젯이 판정을 보여 줌 / When 위젯과 앱의 종합 판정 카드를 나란히 본다 / Then 단계 이름의 색이 같다
  - 확인 방법: 위젯을 본 뒤 앱을 열어 종합 판정 카드의 단계 이름을 보고, 두 색이 같은지 본다. 나란히 보기 어려우면 위젯과 앱 화면을 각각 화면 캡처해 사진 앱에서 번갈아 본다.
- [ ] R-37 (그림, 흐리게 보임, 눌러도 반응 없음): Given 판정, 키 안내 / When 버튼을 보고, 키 안내에서 버튼을 누른다 / Then 버튼이 앱의 새로 고침과 같은 그림이고, 키 안내에서는 흐리게 보이며 눌러도 앱이 열리지 않고 아무 일도 없다
  - 확인 방법: 판정이 보이는 위젯의 오른쪽 위 버튼 그림을 앱의 시장 분위기 화면 오른쪽 위 새로 고침 버튼 그림과 견준다. R-18처럼 키 하나를 지워 키 안내로 만든 뒤, 두 위젯의 버튼이 흐린지 보고 버튼을 눌러 앱이 열리지 않고 위젯도 바뀌지 않는지 본다. 끝나면 키를 다시 저장한다.
- [ ] R-38: Given 위젯이 판정을 보여 줌, 마지막으로 받은 뒤 새 종가가 나옴, 앱이 꺼져 있음 / When 새로 고침 버튼을 누른다 / Then 진행 표시가 돈 뒤 날짜가 새 종가 날짜로 바뀐다. 앱은 열리지 않는다
  - 확인 방법: 수동 작업 3대로 전날 저녁에 위젯을 놓고 앱을 강제 종료해 둔다. 새 종가가 나온 아침에 위젯의 날짜가 전날 것인지 보고, 오른쪽 위 새로 고침 버튼을 누른다. 버튼 자리에 진행 표시가 돈 뒤 날짜가 새 종가 날짜로 바뀌는지, 그동안 앱이 열리지 않는지 본다.
- [ ] R-39: Given 작은 위젯과 큰 위젯을 함께 놓음 / When 한 위젯의 새로 고침을 누른다 / Then 두 위젯 모두 버튼 자리에 진행 표시가 돌고, 그동안 버튼 자리를 다시 눌러도 아무 일이 없다. 나머지는 그대로다
  - 확인 방법: 작은 위젯과 큰 위젯을 한 화면에 놓고, 마지막으로 받기를 시작한 지 1분이 넘은 때에 작은 위젯의 새로 고침을 누른다. 두 위젯 모두 버튼 자리에 진행 표시가 도는지, 돌고 있는 동안 진행 표시를 눌러도 앱이 열리지 않고 아무 일도 없는지, 글과 날짜는 그대로인지 본다. 진행 표시가 짧으면 화면 녹화로 찍어 본다.
- [ ] R-41 (1분 안에는 받지 않음, 앱을 끈 채로도): Given 위젯이 판정을 보여 줌, 마지막으로 받기를 시작한 지 1분이 넘음 / When 새로 고침을 눌러 진행 표시가 풀리면 곧바로 앱을 강제 종료(설정 > 앱 > 학반꿀 > 강제 종료)하고, 처음 누른 때부터 1분이 지나기 전에 다시 누른다 / Then 둘째에는 진행 표시가 1초쯤만 보였다가 버튼으로 돌아온다(첫째보다 짧다)
  - 확인 방법: 미리 설정 > 애플리케이션 > 학반꿀 화면을 최근 앱 목록에 열어 두고, 앱을 마지막으로 쓴 지 1분이 넘은 때에 한다. 빠른 설정의 화면 녹화를 켜고 위젯의 새로 고침을 누른 시각을 기억한다. 진행 표시가 풀리면 곧바로 학반꿀 앱 정보 화면에서 "강제 종료"를 누르고, 홈으로 돌아와 처음 누른 때부터 1분 안에 새로 고침을 다시 누른다. 녹화를 돌려 보며 둘째의 진행 표시가 1초쯤만 보였다가 버튼으로 돌아오는지(첫째보다 짧은지) 본다.
- [ ] R-42: Given 위젯이 판정을 보여 줌, 마지막으로 받기를 시작한 지 1분이 넘음, 비행기 모드 / When 새로 고침을 누른다 / Then 진행 표시가 돈 뒤 버튼으로 돌아오고, 판정과 날짜가 그대로이며 실패 안내가 없다. 잠시 기다려도 진행 표시가 다시 돌지 않는다(R-27)
  - 확인 방법: 앱을 마지막으로 쓴 지 1분이 넘은 때에 비행기 모드를 켜고 위젯의 새로 고침을 누른다. 진행 표시가 돈 뒤 버튼으로 돌아오는지, 단계 이름과 날짜가 그대로이고 "데이터를 받지 못했습니다" 같은 안내가 없는지 본다. 그대로 2~3분 지켜보며 진행 표시가 저절로 다시 돌지 않는지 본다. 끝나면 비행기 모드를 끈다.
- [ ] R-43 (앱이 꺼진 뒤): Given 위젯이 판정을 보여 줌 / When 새로 고침을 눌러 진행 표시가 도는 동안 앱을 강제 종료하고, 앱을 다시 열었다가 홈으로 나간다 / Then 위젯의 버튼 자리가 진행 표시가 아니라 새로 고침 버튼이다
  - 확인 방법: 진행 표시가 도는 동안 강제 종료하기 쉽게 비행기 모드를 끄고, 설정 > 애플리케이션 > 학반꿀 화면을 분할 화면이나 최근 앱 목록에 열어 둔다. 앱을 마지막으로 쓴 지 1분이 넘은 때에 위젯의 새로 고침을 누르고, 진행 표시가 도는 동안 곧바로 "강제 종료"를 누른다. 앱을 열었다가 홈으로 나가 위젯의 버튼 자리가 새로 고침 버튼인지 본다. 진행 표시가 다 돌기 전에 강제 종료하지 못했으면 1분 뒤 다시 한다.
