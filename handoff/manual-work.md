기능: 설정
변경: 버전업-001 (CS-002)

## 수동 작업

- [ ] 1. 앱을 기기나 에뮬레이터에 설치한다
  Android Studio에서 이 저장소를 열고, 위쪽 기기 목록에서 Android 8.0(API 26) 이상인 기기나 에뮬레이터를 고른 뒤 Run(▶)을 누른다. 이미 설치한 앱이 있으면 그 위에 설치되어 저장한 키가 남는다. 수동 확인 R-10을 위해 화면 키보드가 뜨는 기기로 한다(에뮬레이터에서 컴퓨터 자판으로 치면 화면 키보드가 안 뜰 수 있다. 그러면 에뮬레이터 설정 > 시스템 > 언어 및 입력에서 화면 키보드를 켠다).
- [ ] 2. 두 출처의 맞는 키를 준비해 둔다
  Twelve Data는 `https://twelvedata.com/register`, FRED는 `https://fredaccount.stlouisfed.org/apikeys`에서 받은 키를 기기의 메모 앱 등에 복사해 둔다(키는 저장소나 채팅에 올리지 않는다). 키를 지우는 확인(R-04, R-15, R-44 등)을 한 뒤에는 설정 화면에서 다시 저장해 둔다.
- [ ] 3. 확인 중 상태를 볼 때 쓸 느린 네트워크를 준비한다
  수동 확인 R-32, R-37은 키를 확인하는 동안에 보거나 손을 써야 한다. 에뮬레이터라면 오른쪽 도구 막대의 ⋯(Extended controls) > Cellular에서 Network type을 GSM, Signal strength를 Poor로 바꾼다(Wi‑Fi는 끈다). 실제 기기라면 개발자 옵션의 네트워크 속도 제한이나 약한 신호의 장소를 쓴다. 확인이 끝나면 원래대로 되돌린다.

## 수동 확인

- [ ] R-02: Given 시장 분위기 화면 / When 메뉴의 "설정"을 눌러 설정 화면을 연다 / Then 위에서 아래로 위쪽 줄(뒤로 가기 버튼, "설정"), 안내 "데이터를 받으려면 출처마다 키가 필요합니다. 키는 이 기기에만 저장됩니다.", 출처 카드 순서로 보인다
  확인 방법: 시장 분위기 화면의 메뉴(점 세 개) > "설정"으로 설정 화면을 연다. 맨 위 줄 왼쪽에 뒤로 가기 화살표와 "설정"이 있는지, 그 아래 안내 "데이터를 받으려면 출처마다 키가 필요합니다. 키는 이 기기에만 저장됩니다.", 그 아래 출처 카드가 이 순서로 오는지 본다.
- [ ] R-03 (카드 표시): Given 설정 화면 / When 화면을 본다 / Then Twelve Data 카드가 위에, FRED 카드가 그 아래에 보인다
  확인 방법: 시장 분위기 화면의 메뉴(점 세 개) > "설정"으로 설정 화면을 연다. 첫 카드가 Twelve Data, 그 아래 카드가 FRED인지 본다.
- [ ] R-04: Given Twelve Data에는 키가 저장되어 있고 FRED에는 키가 없음 / When 설정 화면을 연다 / Then 두 카드 모두 출처 이름, 그 아래 한 줄("주식과 ETF 가격", "금리와 채권 지표"), 출처 이름 오른쪽의 딱지가 보인다
  확인 방법: Twelve Data 키는 저장된 채로 두고 FRED 카드는 "키 지우기"로 지워 키 없음으로 만든다. 설정 화면에서 두 카드 모두 출처 이름, 그 아래 한 줄(Twelve Data "주식과 ETF 가격", FRED "금리와 채권 지표"), 이름 오른쪽 딱지가 있는지 본다.
- [ ] R-05 (딱지의 글과 색): Given Twelve Data에 맞는 키가 저장됨, FRED에 키 없음 / When 설정 화면을 열고, FRED에 틀린 키 `wrongkey1234`를 넣어 저장을 누른다 / Then Twelve Data의 딱지는 파란 "저장됨"이고, FRED의 딱지는 저장을 누르기 전에는 회색 "키 없음", 거절된 뒤에는 빨간 "틀림"이다. 시장 분위기 화면의 키 안내 카드에 보이는 딱지와 글과 색이 같다
  확인 방법: R-04의 상태(Twelve Data 저장됨, FRED 키 없음)에서 Twelve Data 딱지가 파란 "저장됨", FRED 딱지가 회색 "키 없음"인지 본다. FRED 입력 칸에 `wrongkey1234`를 넣고 "저장"을 눌러, 확인이 끝난 뒤 FRED 딱지가 빨간 "틀림"이 되는지 본다. 시장 분위기 화면과 견주려면, "저장"을 누르기 전(FRED 키 없음)에 위쪽 줄의 뒤로 가기 버튼으로 시장 분위기 화면에 가서 키 안내 카드의 Twelve Data "저장됨", FRED "키 없음" 딱지의 글과 색이 설정 화면과 같은지 본다. 시장 분위기 화면의 "틀림" 딱지는 저장된 키가 틀림이 될 때만 보여 만들기 어려우므로, 설정 화면의 빨간 "틀림"이 키 안내 카드의 딱지들과 같은 크기와 모양인지 본다.
- [ ] R-06 (요소 표시): Given 키가 없는 출처 / When 설정 화면을 연다 / Then 그 카드에 이름표 "API 키", "키를 붙여 넣으세요"가 보이는 빈 입력 칸, "키 발급받기"와 그 아래 "무료, 카드 등록 없음", "저장" 버튼이 보인다
  확인 방법: 키가 없는 카드(R-04의 FRED 카드)를 본다. 이름표 "API 키", "키를 붙여 넣으세요"가 보이는 빈 입력 칸, 왼쪽 "키 발급받기"와 그 아래 "무료, 카드 등록 없음", 오른쪽 "저장" 버튼이 있는지 본다.
- [ ] R-07 (요소 표시): Given 키가 저장된 출처 / When 설정 화면을 연다 / Then 그 카드에 입력 칸, 발급 안내, 저장 버튼이 없고, 점 12개와 키의 끝 네 글자로 가려진 키, 그 오른쪽의 키 보기 버튼, "키 지우기" 버튼이 보인다
  확인 방법: 키가 저장된 카드(Twelve Data)를 본다. 입력 칸, 발급 안내, 저장 버튼이 없고, "•••••••••••• " 뒤에 저장한 키의 끝 네 글자가 오는 가려진 키, 그 오른쪽 눈 모양 버튼, 오른쪽 아래 "키 지우기" 버튼이 있는지 본다.
- [ ] R-08 (표시): Given 키가 없는 출처 / When 틀린 키 `wrongkey1234`를 넣고 저장을 누른다 / Then 입력 칸에 `wrongkey1234`가 남아 있고 칸의 테두리가 빨갛다. 발급 안내와 저장 버튼은 그대로 있다
  확인 방법: 키가 없는 카드에 `wrongkey1234`를 넣고 "저장"을 누른다. 확인이 끝난 뒤 입력 칸에 `wrongkey1234`가 남아 있는지, 칸의 테두리가 빨갛고 굵어졌는지, "키 발급받기"와 "저장" 버튼이 그대로 있는지 본다.
- [ ] R-10: Given 키가 없는 출처의 빈 입력 칸 / When 글자를 치고, 지운 뒤 복사해 둔 키를 붙여 넣는다 / Then 친 글자와 붙여 넣은 키가 칸에 들어간다. 키보드가 올라와 있어도 입력 칸과 저장 버튼을 볼 수 있다
  확인 방법: 키가 없는 카드의 빈 입력 칸을 눌러 자판으로 글자를 몇 개 친다. 키보드가 올라온 채로 화면을 위아래로 밀어 그 카드의 입력 칸과 "저장" 버튼이 보이는지 본다(FRED 카드로도 해 본다). 친 글자를 모두 지운 뒤, 메모 앱 등에서 복사해 둔 키를 칸을 길게 눌러 "붙여넣기"하고 칸에 들어가는지 본다.
- [ ] R-13 (긴 키의 표시): Given FRED에 32글자 키가 저장됨 / When 키 보기 버튼을 누른다 / Then 가려진 키 자리에 키 전체가 잘리지 않고 보인다(한 줄에 다 들어가지 않으면 다음 줄로 넘어간다). 버튼은 키 가리기 모양(눈에 빗금)으로 바뀌고, 다시 누르면 키가 가려진다
  확인 방법: FRED 카드에 수동 작업 2의 FRED 키(32글자)를 저장한다. 눈 모양 버튼을 눌러 키 전체가 잘리지 않고 보이는지(한 줄에 다 들어가지 않으면 다음 줄로 넘어가고 칸이 높아지는지), 버튼이 눈에 빗금이 그어진 모양으로 바뀌는지 본다. 버튼을 다시 눌러 키가 가려지는지 본다.
- [ ] R-14: Given 키가 저장된 출처 / When "키 지우기"를 누른다 / Then "이 키를 지울까요?"라고 묻는 창이 뜬다
  확인 방법: 키가 저장된 카드에서 "키 지우기"를 누르고 "이 키를 지울까요?" 창이 뜨는지 본다. 창은 "취소"로 닫는다.
- [ ] R-15 (브라우저 열기): Given 키가 없는 두 출처 / When 카드마다 "키 발급받기"를 누른다 / Then 브라우저에서 Twelve Data는 `https://twelvedata.com/register`, FRED는 `https://fredaccount.stlouisfed.org/apikeys`가 열린다
  확인 방법: 두 카드를 키 없음으로 만든 뒤(키 지우기) 각 카드의 "키 발급받기"를 누른다. 열린 브라우저의 주소창이 Twelve Data는 `https://twelvedata.com/register`, FRED는 `https://fredaccount.stlouisfed.org/apikeys`인지 보고, 기기의 뒤로 가기로 앱에 돌아와 다른 카드도 본다. 확인 뒤 두 키를 다시 저장해 둔다.
- [ ] R-26 (비활성 모양): Given 키가 없는 출처의 빈 입력 칸 / When 저장 버튼을 누르고, 그 뒤 글자 하나를 넣는다 / Then 칸이 비어 있을 때는 저장 버튼이 흐리게 보이고 눌러도 반응하지 않는다. 글자를 넣으면 파란 버튼이 된다
  확인 방법: 키가 없는 카드의 입력 칸이 빈 채로 "저장" 버튼이 흐린 회색인지 보고, 눌러도 아무 일이 없는지 본다. 칸에 글자 하나를 넣고 버튼이 파란 바탕에 흰 글자로 바뀌는지 본다.
- [ ] R-28 (표시): Given 저장되어 있던 키가 틀림이 된 상태(실제로 만들기 어려우면 Android Studio의 미리보기로 본다) / When 설정 화면을 연다 / Then 딱지가 "틀림"이고, 키는 가려진 채이며, 그 아래에 "키가 거절됐습니다. 지우고 다시 넣어 주세요."가 보인다. "키 지우기" 버튼이 있다
  확인 방법: 실제로 만들기 어려우므로 Android Studio에서 `feature/settings/presentation/SettingsScreen.kt`를 열고 Split 보기의 미리보기 "확인 중과 거절된 키"의 FRED 카드를 본다. 딱지가 "틀림"인지, 키가 가려진 채인지, 칸의 테두리가 빨갛고 그 아래에 알림 아이콘과 "키가 거절됐습니다. 지우고 다시 넣어 주세요."가 있는지, "키 지우기" 버튼이 있는지 본다.
- [ ] R-32 (진행 표시와 "확인 중"): Given 키가 없는 출처에 키를 넣음 / When 저장을 누른다 / Then 확인이 끝날 때까지 저장 버튼 자리에 돌아가는 진행 표시와 "확인 중"이 보이고, 그 카드의 입력 칸은 고칠 수 없다. 다른 카드는 그대로 쓸 수 있다(확인이 금방 끝나 보기 어려우면 모양은 Android Studio의 미리보기로 본다)
  확인 방법: 수동 작업 3의 느린 네트워크를 켜고, 키가 없는 카드에 키를 넣고 "저장"을 누른다. 확인이 끝날 때까지 저장 버튼 자리에 돌아가는 고리와 "확인 중"이 보이는지, 그 카드의 입력 칸이 흐려지고 눌러도 고칠 수 없는지 본다. 그동안 다른 카드의 입력 칸이나 버튼을 눌러 쓸 수 있는지 본다. 확인이 너무 빨리 끝나면 모양은 미리보기 "확인 중과 거절된 키"의 Twelve Data 카드로 본다. 확인 뒤 네트워크를 원래대로 둔다.
- [ ] R-33 (앱을 다시 켜면 가림): Given 키 보기를 눌러 키 전체가 보이는 상태 / When 앱을 껐다 다시 켜고 설정 화면을 연다 / Then 키가 가려진 상태로 보인다
  확인 방법: 키가 저장된 카드에서 눈 모양 버튼을 눌러 키 전체를 보인다. 최근 앱 화면에서 학반꿀을 위로 밀어 닫고, 다시 열어 메뉴 > "설정"으로 들어간다. 키가 가려진 모양으로 보이는지 본다.
- [ ] R-35: Given "이 키를 지울까요?" 창이 떠 있음 / When 취소를 누른다 / Then 창이 닫히고 키와 딱지가 그대로다
  확인 방법: 키가 저장된 카드에서 "키 지우기"를 눌러 창을 띄우고 "취소"를 누른다. 창이 닫히고 가려진 키, 딱지 "저장됨", "키 지우기" 버튼이 그대로인지 본다.
- [ ] R-37 (화면을 벗어났다 돌아오기): Given 키를 넣고 저장을 누른 직후(확인 중) / When 뒤로 가기로 시장 분위기 화면에 갔다가 다시 설정 화면에 들어온다 / Then 그때의 결과가 보인다. 아직 확인 중이면 확인 중 표시, 저장됐으면 저장됨의 모양, 저장하지 못했으면 넣었던 키와 그 안내다
  확인 방법: 수동 작업 3의 느린 네트워크를 켜고, 키가 없는 카드에 키를 넣고 "저장"을 누른 직후 위쪽 줄의 뒤로 가기 버튼으로 시장 분위기 화면에 간다. 곧바로 메뉴 > "설정"으로 다시 들어와 확인 중 표시와 넣은 키가 보이는지 본다. 한 번 더 나갔다가 확인이 끝난 뒤 들어와 결과가 보이는지 본다(맞는 키면 저장됨의 모양, `wrongkey1234`처럼 틀린 키면 넣은 키와 빨간 테두리, 그 안내). 확인 뒤 네트워크를 원래대로 둔다.
